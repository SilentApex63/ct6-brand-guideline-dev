## Guidance

The full emblem is approved as the primary brand identity asset for large brand moments. It is detailed, metallic, tactical, and aligned with the Command Glass Ops direction.

The full emblem should not be used as the final small app icon or favicon. For those uses, create a simplified CT6/cobra mark derived from the same identity language.

## Deployment note

Do not recreate `vercel.json`. Vercel is using project settings and the app now deploys successfully without that file.
