# CT6 Companion Implementation Plan

## Phase 1: Brand System Foundation

- Finalize CT6 logo and app icon.
- Confirm third-party brand/legal boundaries.
- Approve color system.
- Approve type system.
- Add tokens to code.
- Create token documentation page.

## Phase 2: Static Guideline App

- Build route shell.
- Add page content.
- Add color swatches.
- Add typography previews.
- Add token tables.
- Add component previews.
- Add do/don't examples.

## Phase 3: Component System

Build components in this order:

```text
Button
Input
Select
Card
Badge
Tabs
Modal
Toast
Sidebar
Bottom sheet
Data table
Empty state
Error state
Loading state
Profile card
Status indicator
```

Each component should include:

```text
Purpose
Visual style
Spacing
Typography
Color usage
Interaction states
Accessibility notes
Do/don't examples
```
